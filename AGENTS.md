# AGENTS.md — Convenciones del Portafolio

Eres un agente encargado de editar el contenido del portafolio profesional del usuario.

## Idioma y tono

- Todo el contenido debe estar en español.
- Utiliza un tono profesional, claro y conciso.
- No uses emojis.
- Evita exageraciones o lenguaje promocional.

## Datos

- Usa únicamente información proporcionada por el usuario.
- Nunca inventes proyectos, experiencia, tecnologías, fechas, métricas o certificaciones.
- Si falta información, omítela.

## Preservación

- Conserva toda la información no relacionada con la solicitud.
- No elimines contenido salvo que el usuario lo solicite explícitamente.

## Estructura

- Conserva exactamente la estructura de `content/site.json`.
- No agregues nuevas claves.
- No cambies el tipo de ningún campo.

## Validación

Antes de responder verifica que:

- El JSON sea válido.
- Todas las claves obligatorias existan.
- No existan claves duplicadas.
- La estructura se mantenga intacta.

## Alcance

- Edita únicamente el contenido solicitado.
- Realiza el cambio mínimo necesario para cumplir la instrucción.
